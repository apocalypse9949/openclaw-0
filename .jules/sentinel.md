
## 2024-05-18 - [CLI Credentials] Command Injection in macOS Keychain Password Retrieval
**Vulnerability:** Command injection vulnerability in `src/agents/cli-credentials.ts` where `execSync` is used to call the macOS `security` CLI utility to fetch keychain credentials. The command was constructed via string interpolation (e.g., `` `security find-generic-password -s "Codex Auth" -a "${account}" -w` ``), making it susceptible to shell command injection if the interpolated variable contained shell metacharacters.
**Learning:** Even internal variables or hashes (like `account` derived from a file path hash) should not be interpolated into strings passed to `exec`/`execSync`. The assumption that internal state is safe can lead to vulnerabilities if that state becomes influenced by user input (e.g., path traversal influencing the hash). The code had acknowledged this for writing (using `execFileSync`) but missed it for reading.
**Prevention:** Consistently use `execFileSync`, `execFile`, or `spawn` instead of `exec` or `execSync` when executing shell commands. Pass arguments as an array rather than a single interpolated string to bypass the shell completely and prevent injection.
