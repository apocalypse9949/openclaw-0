## 2025-05-06 - Command Injection via MacOS Security Utility Arguments
**Vulnerability:** Command injection vulnerability identified in `readClaudeCliKeychainCredentials` and `readCodexKeychainAuthRecord` inside `src/agents/cli-credentials.ts`. The arguments to the `security` command were passed as a single string via `execSync` combined with template literals.
**Learning:** Using `execSync` with template literals or string concatenation allows variables containing shell metacharacters (e.g., ``$()`, backticks, `;`) to be evaluated by the shell before the command executes. Even if the expected input is "safe" or static, it violates the principle of avoiding shell interpretation of dynamic values when calling out to command-line tools.
**Prevention:** Always prefer `execFileSync` or `spawn` with an array of string arguments for executing processes, so the OS safely treats arguments as literal tokens and bypasses any shell interpretation. This ensures safe interactions with system utilities like macOS's `security`.
