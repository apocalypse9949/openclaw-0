## 2026-07-25 - Command Injection via execSync\n**Vulnerability:** Command injection risk when using `execSync` with string interpolation for the macOS `security` utility in `src/agents/cli-credentials.ts`.\n**Learning:** Even if variables interpolated into an `exec` or `execSync` string appear safe (e.g. hashes or constants), they are evaluated by the shell. Any future changes that introduce untrusted input could lead to command execution.\n**Prevention:** Always use `execFileSync`, `execFile`, or `spawn` with an array of arguments to completely bypass shell evaluation.
