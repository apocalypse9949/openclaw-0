## 2026-06-28 - SQLite SQL Injection via PRAGMA String Interpolation
**Vulnerability:** SQL injection via unsanitized table names dynamically interpolated into SQLite PRAGMA commands like `PRAGMA table_info(...)` or `PRAGMA index_list(...)`. Note that the standard SQLite mechanism does not support parameter binding in normal `PRAGMA` statements.
**Learning:** Dynamic PRAGMA statements typically require identifiers, which are difficult to properly sanitize or bind as parameters natively in standard statements. Even functions like `quoteSqliteIdentifier` might fail to protect against all attack vectors or break certain functionalities if improperly implemented.
**Prevention:** Rather than using `PRAGMA table_info(...)` with string interpolation, use the parameterized table-valued functions provided by modern SQLite: `SELECT * FROM pragma_table_info(?)` and `SELECT * FROM pragma_index_list(?)`. This natively supports query parameterization and safely resolves dynamic table inputs natively.
